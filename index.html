Cycle Structure›

The program runs on a 6-day rotating cycle — Upper A / Lower A / Rest / Upper B / Lower B / Rest — de-coupled from the calendar week. Training frequency is driven by recovery, not the calendar.

Each muscle group is trained twice per cycle (every ~6 days), hitting both an A and B variant with different primary exercises and emphases. Upper sessions cover chest, back, delts, and arms. Lower sessions cover quads, hamstrings, glutes, calves, and core.

The Optional Upper session is a low-intensity specialisation session (~2 RIR every set). Run it when recovery allows — between Lower B and the next Upper A, or as a standalone extra. It does not count toward the deload cycle counter.

If you miss a session, pick up exactly where you left off. Never cram two sessions into one day to catch up, and never skip a session to stay calendar-aligned.
Intensity — RIR Targets›

This program uses per-set RIR targets rather than a single blanket prescription. Heavy compounds use a graduated approach (e.g. 2/2/1 across S1–S3). Isolation work typically finishes at 0–1 RIR on the final set.

Check the note on each exercise card for the specific RIR target per set. The Optional session runs all exercises at approximately 2 RIR — it is volume accumulation, not a grinding session.

Stop one rep before technical breakdown on heavy compounds. Form breakdown on a squat, RDL, or bench press is where injuries happen — never grind a technical failure on a barbell compound.

Progressive Overload›

Double progression is the primary overload method:

  • Hit the top of the rep range across all sets at the prescribed RIR → add weight next session (2.5kg upper / 5kg lower)
  • Adding weight drops you back to the lower end of the range — work back up over subsequent sessions
  • For high-rep isolations (15–25), use smaller increments where plates aren't practical
  • For unilateral movements, let the weaker side determine the load
Calf Training›

Both lower sessions use standing calf raises. 2023 research found standing raises produced significantly greater gastrocnemius hypertrophy than seated, while soleus growth was comparable between both.

Vary toe angle across sets: neutral covers both heads evenly, toes slightly out biases the medial head, toes slightly in biases the lateral head.
Elbow Management›

Rope pushdown is the primary tricep isolation in both upper sessions, loading the tricep at a comfortable angle without an overhead stretched position.

Overhead tricep extension is available as an alternate — but only when the right elbow is completely symptom-free. It is the primary aggravating mechanism for the right distal triceps tendon and must not be used at any sign of irritation.

Monitor elbow response to accumulated push volume across the cycle. If irritation increases, reduce pushdown sets first before making any other changes.

Warm-Up & Cardio›

General warm-up: 5 minutes treadmill at 2–4% incline, 5.5–6.5 km/h. Noticeably warmer and breathing slightly elevated before touching a barbell.

Compound pyramid: every primary compound needs its own warm-up set sequence before working sets:

  • Set 1 — 40–50% working weight, 8–10 reps. Pattern only, zero fatigue.
  • Set 2 — 60–70% working weight, 4–5 reps.
  • Set 3 — 80–90% working weight, 2–3 reps.
  • Rest 2 minutes after the final warm-up set, then begin working sets.

Secondary compounds later in the session — 1 lighter set only. Isolations — nothing needed.

Pull-up warm-up (specific): bodyweight is ~95% of working weight at current loading, so a full pyramid would arrive at near-working intensity. Instead: 1 set scapular pulls (8–10 reps) + 3–4 bodyweight pull-ups at easy effort. Straight into weighted sets.

Cardio: after Upper sessions only — never after Lower. 15–20 min, 2–3× per week.

Incline: 10–12% · Speed: 5.5–6.5 km/h · Duration: 15–20 min. If resistance session quality declines, trim cardio to 12–15 min before touching the resistance program.
Deload Protocol›

After every 4–5 cycles (~5–6 weeks), run a deload. Keep all exercises — reduce every session to 1–2 sets per exercise and drop load by 30–40%.

Not optional at advanced training intensity. Accumulated joint and central fatigue blunts progress and increases injury risk. The deload cycle counter tracks the 4 main sessions only — the optional session does not count toward it.
